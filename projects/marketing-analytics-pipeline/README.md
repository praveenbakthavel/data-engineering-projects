# Marketing Analytics Pipeline

## Purpose

Build a small, reproducible data engineering project that turns raw marketing campaign data into validated, KPI-ready analytics outputs.

This is Project 01 in the data engineering portfolio evidence layer.

## Why this project exists

This project converts existing professional strengths in marketing analytics, SQL, Python, BigQuery-style reporting, metric standardization, and dashboard-ready data preparation into public engineering evidence.

## Business Question

How can raw marketing campaign activity be transformed into reliable daily and channel-level KPIs for business reporting?

## Initial KPIs

The first version focuses on five core KPIs:

- sessions
- leads
- conversions
- conversion rate
- cost per lead

## Technology Stack

Initial local/free stack:

- Python
- Pandas
- DuckDB
- pytest
- Ruff / Black later
- Markdown documentation

Future additions only after the first pipeline works:

- dbt Core

- Docker
- GitHub Actions

The seed CSV is intentionally small so the first implementation can be built and tested quickly. The full external dataset should be fetched and materialized only after the starter pipeline is working.

## Version 0 Definition of Done

Version 0 is done when:

- The project can read the seed marketing campaign CSV.
- Required columns are validated.
- Numeric metrics are cleaned.
- KPI output is generated by date and channel.
- Basic pytest tests pass.
- README and architecture notes explain the flow.

## First Implementation Flow

```text
Raw campaign CSV
        ↓
```
